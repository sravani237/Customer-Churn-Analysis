# Customer Churn Analysis

## Project Overview
This project analyzes customer churn to understand customer retention patterns and identify factors associated with customers leaving a service.

## Tools & Technologies
- Excel — Data cleaning and preparation
- SQL (PostgreSQL) — Data analysis and querying
- Python (Pandas) — Customer churn analysis
- Power BI — Interactive dashboard and data visualization

## Key Performance Indicators
- Total Customers
- Churned Customers
- Retained Customers
- Churn Rate
- Average Customer Charges

## Analysis Performed
- Analyzed customer churn and retention.
- Examined churn by tenure, internet service, payment method, and contract type.
- Compared average monthly charges for churned and retained customers.
- Created a Power BI dashboard to present key metrics and insights.

## Key Findings
- Total customers: 7,043
- Churned customers: 1,869
- Retained customers: 5,174
- Churn rate: 26.54%

## Project Files
The repository contains the project files for the Excel data preparation, SQL queries, Python analysis, and Power BI dashboard.

## Conclusion
This project demonstrates the use of Excel, SQL, Python, and Power BI to analyze customer churn and communicate findings through data visualization.
